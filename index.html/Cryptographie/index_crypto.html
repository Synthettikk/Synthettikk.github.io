Menu Crypto

Les pages de cette section présentent quelques cryptosystèmes classiques et permettent de jouer avec via une interface graphique. Pour le moment, seulement des méthodes de chiffrement sont présentées. Une méthode de hashage (MD4) sera bientôt disponible.
Note : Les implémentations données ici (même pour les cryptosystèmes d'actualité) ont pour seul but d'être pédagogiques et ne doivent pas être utilisées pour de la sécurité réelle.
